# Enhanced Prompt

**Task:** Solve the provided question papers with comprehensive, student-friendly answers.

---

## Output Requirements:

### File Structure:
- Create separate files: `answer{paper_no}.md` for each paper
- Organize answers sequentially by question number

---

## Answer Quality Standards:

### Length & Depth (8-10 marks criterion):
- Each answer should be **sufficiently detailed** to earn 8-10 marks in SPPU examinations
- Include **all key points** examiners look for
- Provide **proper explanations**, not just bullet points
- Aim for 400-600 words per 8-mark answer (adjust proportionally for other marks)

### Clarity & Simplicity:
- Use **simple, conversational language** (suitable for a 15-year-old)
- Avoid unnecessary jargon; when technical terms are needed, explain them immediately
- Break complex concepts into **digestible chunks**
- Use **short paragraphs** (3-4 sentences maximum)

---

## Visual Learning Elements:

### Diagrams & Visuals:
- Include **clear, labeled diagrams** where applicable
- Use ASCII art, markdown tables, or describe diagrams that should be drawn
- Add **flowcharts** for processes and algorithms
- Include **before/after comparisons** when relevant

### Visual Techniques:
- Use **analogies and real-world examples** (compare to everyday objects/situations)
- Create **mental images** through descriptive language
- Add **comparison tables** for contrasting concepts
- Use **emojis or symbols** sparingly to mark important points (⭐ for key concepts, ✅ for steps)
- Include **numbered steps** for procedures
- Use **bold**, *italics*, and `code blocks` strategically for emphasis

---

## Pedagogical Approach:

### "Read Once & Understand" Strategy:
- Start with a **simple one-line summary** of the concept
- Use the **"What → Why → How"** structure
- Include **transitional phrases** to guide the reader
- End each answer with a **brief recap** or conclusion
- Add **memory triggers** or mnemonics where helpful

### Example Structure for Each Answer:
```
1. **Quick Overview** (1-2 sentences)
2. **Main Explanation** with subheadings
   - Use analogies
   - Include diagrams
   - Provide examples
3. **Step-by-step breakdown** (if applicable)
4. **Key Points Summary** (bullet points)
5. **Pro Tip for Exams** (how to remember or present this)
```

---

## Exam Strategy Guidance:

### For Each Answer, Include:
- **"How to write this in your exam"** section showing:
  - Time management (how many minutes to spend)
  - What to write in introduction
  - Which points are mandatory vs. bonus
  - How to structure for maximum marks
  - What diagrams are essential vs. optional

- **Mark Distribution Hints:**
  ```
  Introduction: 1 mark
  Main explanation: 4-5 marks
  Diagram: 1-2 marks
  Example/Application: 1 mark
  Conclusion: 1 mark
  ```

---

## Additional Features:

- **Common Mistakes to Avoid** section
- **What examiners want to see** callout boxes
- **Related concepts** for deeper understanding
- **Practice tips** - how student can rewrite and personalize the answer
- **Self-check questions** at the end

---

## Tone & Style:
- Write as a **friendly tutor**, not a textbook
- Use **encouraging language**
- Make it **engaging** - the student should enjoy learning
- Be **conversational** but academically sound

---

**Goal:** After reading once, the student should be able to close the document and rewrite a complete, mark-worthy answer in their own words during the exam.
